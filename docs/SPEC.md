# 硬规范 SPEC.md v1.0 —— 代码动效视频制作总纲

> 每次做片子前必读。定位：`SKILL.md` 是**技法手册**（怎么画、怎么渲、怎么查），本文件是**开工总纲**（开工前必须有什么、按什么顺序做、做到什么标准算过）。
> 技法细节查 skill；本文件只放"不做就返工"的硬性规定。冲突时以本文件为准。

---

## §A 开工前 setup 清单（缺一项不开工）

from Hamza 教程 + awesome-opus-5-5-videos 三段式验收。prompt 只占 10%，这 90% 先备齐：

1. **风格文件夹**：调色板（色值）、字体（文件名+字重）、母题符号（logo/字母/核心图形）、3–5 张参考帧。
2. **参考库已索引**：先查 `docs/REPOS.md` 路线决策表，确认本次任务走哪条路线；需要时去对应 `repos/` 读原文。
3. **规则已加载**：本 SPEC + motion-director skill 已读。
4. **brief 定稿**（一段话）：给谁看、故事三节拍（起/转/收）、时长、画幅（16:9 / 9:16 / 1:1）。**画幅 9:16 时默认走 §K 自媒体安全区**（用户大概率发抖音/小红书/视频号）。
5. **三方案确认**（from xilo-opus-video）：brief 之前先给三个拉开差别的方案（A 稳妥 / B 换画面语言 / C 换讲法）+ 关键帧或 2–4 秒小样，让用户选。这是防"一次定稿返工"的最便宜保险。
6. **验收标准先行**：三段式——① brief 定稿 → ② 最难的 2–4 秒先出小样并通过 → ③ 全片可复现交付。**小样不过，不许开全片。**
7. **渲染耗时先报价**（from xilo-opus-video）：单帧实测耗时 × 总帧 × 子帧数 × 1.3，开工前报给用户。耗时失控先降子帧/分辨率，不许闷头渲。

## §B 参考帧优先（from awesome-ai-motion）

- 做新场景前，先找或生成**参考帧**（截图、原片静帧、手绘草图都行），贴进工作上下文再动手。
- **视频/图片参考 > 文字描述**。实证：给模型一段参考视频照着做，可接近 1:1；纯文字描述只能得到平均水准。
- 对标时只对标**已验证**的东西。资料分级：原文 / 转述 / 未知；**不拿转述冒充原文**。

## §C 歌词 MV 三铁律（from Claude Pop + PDoomVideo + mexicat）

1. **先锁定歌曲和歌词**，再做画面；时间轴锚定**歌词行的开始时间**，不锚定秒表。
2. **画面逐句回应歌词**：每句歌词至少有一个视觉动作与之对应；歌词大字出现时，背景必须让位（降暗/简化/留白）。
3. 卡拉 OK 逐词高亮；reads 模型：观众一次只理解一个东西，read 没落地不许切（详见 skill §16）。

## §D 声音从画面反推（from Austerlitz + claude-animation-skill）

1. 音效/鼓点触发点**从时间轴数据推导**（节拍网格、事件表），不许人肉对齐。
2. 有距离感的声音按物理给延迟（如声速 343m/s）；cue 标记**早 0.03s**，给混音留头。
3. 混音链固定：合成 → 响度归一 → 检查，不许每次即兴。
4. **响度标准**（from xilo-opus-video）：-14 LUFS，峰值 <-1dBTP。模型听不见，只能看波形/频谱图验收。

## §E 后期栈统一美术（from Austerlitz）

1. **质感是后期给的，不是建模给的**：bloom / 颗粒 / 暗角 / 色差做成**一条可复用的后处理链**，全片共用。
2. 禁止每个场景各写一套后期参数——统一后期 = 统一美术。
3. 颗粒只走编码时滤镜（`noise=alls=6:allf=t`），禁止 canvas 内逐帧随机颗粒（血泪教训见 skill §8）。

## §F 三层细节法则（from claude-animation-skill）

1. 每帧按 **base → texture → edge** 三层画：先铺大关系，再上材质，最后收边缘。
2. 开工前先定**材质清单**（纸纹/金属/辉光分别怎么表现），写进文件头注释，防跨 session 风格漂移。
3. 美学路线一旦选定（黑橙 HUD / 水彩绘本二选一），**视觉词汇不许混用**。

## §G 防猜机制（from claude-animation-skill + Remotion）

1. **Read-first**：开工先读本 SPEC + skill + 相关 repo 原文，不许靠记忆写。
2. **traps.md 持续积累**：每次踩坑记一条（现象 → 原因 → 解法），下次开工前重读。
3. **运行时查阅 > 背诵**：API、笔刷名、参数不确定就去查原文，不许猜（如 p5.brush 的 opacity 是 0–255 不是 0–1）。
4. **确定性四戒**（from hyperframes）：① 不用 Date.now/计时器做视觉；② 不用未播种的 Math.random；③ 渲染中途不 fetch 新资源（全部第 0 帧前加载完）；④ fps/宽高/总时长在第 0 帧前锁定，之后不许改。

## §H 风格库积累（from awesome-opus-5-5-videos）

1. 目标是攒出**"黑橙 HUD 风格库"**：可复用的场景模板、转场、字体模块、后期链预设。
2. 每次做完片子，沉淀：① 能复用的写成模块；② 写进风格库索引（位置：`docs/style-lib/`）；③ 在 REPOS.md 维护规则里记一笔。
3. "一句话出片"的真相是**触发预置风格库**——库越厚，prompt 越短。
4. **风格固定、故事自定**（from lemo-opuscar）：STYLE.md 是不变量，先写自己的 TREATMENT.md 再看样片；样片只学技术不抄故事。做新风格时防止连样片故事一起抄。
5. 新风格的 STYLE.md 按 8 节写：本质 / 材质与渲染 / 色彩逻辑 / 字体与字幕 / 运动质感 / 镜头语法 / 声音调色板 / 坑。

## §I 迭代循环（铁律）

from skill §9/§18，本文件重申为流程纪律：

1. **静帧先行**：关键帧（标题砸中瞬间、切点、转场中间态）抽 PNG，逐张看，不过不往下走。
2. **contact sheet**：全片每 2–3 秒一张拼图，查黑场/重影/溢出。
3. **strip/crop**：关键动作逐帧拼条看预备/跟随；接触点裁剪查穿帮。
4. **对标**：拿静帧和 §B 的参考帧并排放，列差距清单，改，复验。
5. **敢删**：每次迭代列出"删了什么"。高级感来自删掉自由度。
6. **缓存陷阱**：每次输出写新文件名（v2/v3），或查 mtime；不许看缓存旧图当验收。
7. **量化打分**（from xilo-opus-video）：自检按 7 项 1–10 分打分——开场前2秒抓人 / 手机可读（缩到360px宽）/ 动作无匀速无空拍 / 每2–4秒有变化 / 构图主体够大 / 贴合原材料 / 声画同步。**每项 8 分才过**，每轮分数记 `qa/review_log.md`，列 top3 问题只改问题段。
8. **安全区验收**（§K）：9:16 成片逐幕检查——关键文字/字幕无一落在危险区；有遮挡风险的放手机草稿箱实机看一遍。

## §J 路线选择（查 REPOS.md 路线决策表）

- 黑橙 HUD/歌词 MV → mexicat 引擎（有 GPU）/ Canvas 2D 投影（无 GPU）。
- 选错路线 = 返工：水彩笔触画不出 HUD 精确，shader 堆不出手绘温度。**开工前先定路线，定错比做错更贵。**

## §K 自媒体安全区（9:16 默认，2026-10-03 实战沉淀）

用户大概率发抖音/小红书/视频号，9:16 成片必须按安全区排版——**这不是后期检查项，是 brief 阶段就定死的版式约束**。

1. **危险区**：顶部 12%（返回键/标题栏）、底部 22%（描述栏/点赞按钮/进度条）不放任何关键信息。装饰性元素可以进，文字不行。
2. **字幕默认位**：bottom 29%（约 68% 高度处），≥26px/800 粗，半透明深色底衬（`rgba(10,9,8,.5)` + 圆角），关键词高亮 + 橙色下划线。
3. **分幕避让**：内容偏下的幕，字幕必须让位——三选一：① 抬高到 44%；② 放顶部 15%（标题式）；③ 隐藏（当 3D 大字本身就是信息时）。不许字幕和 3D 文字打架。
4. **角标/标注收进安全区**：取景框角标 inset 7%/6%，场景编号下移到 84px。
5. **实机验收**：渲染后放手机草稿箱看一遍，确认描述栏盖不住字，再交付。这是 §I 第 8 项的前置动作。
