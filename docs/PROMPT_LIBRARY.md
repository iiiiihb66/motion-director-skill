## 🔍 为什么这句提示词能逼出惊艳效果？（深度解密）

很多普通的提示词（如*“给我写一个好看的 3D 动画”*）只会让模型输出“深色背景 + 居中大字 + 淡入淡出”的平庸 PPT 式垃圾。这句提示词之所以能产生工业级冲击力，核心在于以下四重心理与技术锚定：

1. **角色与动机锁定（High Stakes Persona）**：
   - *“就好像这是你简历中的作品集”* —— 将任务从简单的“功能实现”直接上升为“顶级动态设计师（Senior Motion Designer / Creative Director）的生死之作”。模型会自发调用最前沿的设计语言（瑞士网格、酸性粗野、错相击打、技术制图）。
2. **极限时间收束（15 秒高密度限制）**：
   - 15 秒是社媒短视频（9:16 竖屏）的黄金生命周期。短时限强制模型消灭任何拖沓的屏保式匀速漂移，每一秒都必须是高能量的视听爆发点。
3. **“全力以赴”的情感指令唤醒（All-in Prompting）**：
   - 连续两次强调*“全力以赴”*，直接解除大语言模型的偷懒模式（Lazy Generation），激活最大 Chain-of-Thought（思维链），自动堆叠最扎实的底层数学、Three.js 深度着色与像素级排版。
4. **HTML-First 交付，无需视频压制**：
   - 交付纯单文件 HTML（`render(t)` 纯时间函数 + WebGL 3D + 2D Canvas + 内嵌音频），秒开即播，避开了 ffmpeg 截图压制的漫长等待，给用户最震撼的即时交互惊喜。

## 🎙️ 独立双音轨与声音平滑避让系统 (Dual Audio Engine)

控制台已实现 **背景音乐（♪）** 与 **人声旁白（🎙）** 的完全独立调控：
- **独立音量与静音**：可单独调节配乐音量/静音，也可单独调节旁白音量/静音。
- **自动避让（Audio Ducking）**：旁白说话时，背景音乐音量自动平滑降低 50%，讲话结束后自动恢复。

## 🛠️ 配合使用的标准架构规范 (Standard Setup)

当向 Coding Agent 发起此任务时，推荐配合以下系统级要求（Setup）：

```markdown
1. 技术栈：单文件 HTML，内嵌 Three.js (r128) + 双画布架构（Canvas #depth 负责 3D，Canvas #screen 负责 2D 1080x1920 矢量文字）。
2. 纯函数：画面是时间 t 的纯函数 render(t)，支持进度条随意拖拽，无状态污染。
3. 错相运动链：严禁所有图层共用一个进度。主体先动 -> 冲击波在过冲峰值触发 -> 装饰随后回稳。
4. 120 BPM 视听对齐：5 大分镜（0s/3s/6s/9s/12s/15s）所有硬切打在整拍上，9.0s 奇点坍缩砸屏。
5. 音频交付：内嵌 Base64 音轨（无外部跨域依赖）+ 专属英文科技旁白。
```
