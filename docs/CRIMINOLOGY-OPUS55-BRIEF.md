# 犯罪学宣传片制作任务

用户要求在这个项目中实际使用 Claude Code / Claude Opus 5.5 制作犯罪学宣传片，只交付可以在浏览器播放的 HTML，不导出视频。

## 定位与叙事

默认是面向普通观众的犯罪学学科宣传，不虚构学校、招生政策、账号名称或课程卖点。犯罪学关心犯罪成因、测量、后果、预防及司法回应；刑事科学的物证分析可以作为开场意象，但不能把整个学科描绘成指纹鉴定或神奇侧写。

片名建议：《犯罪学｜看见真相，理解原因》。结尾主张：“理解犯罪，让伤害止于发生之前。”

建议 42 秒、7 幕，每幕约 6 秒，120 BPM，16:9 / 1920×1080 逻辑画幅。可根据视觉节奏调整到 36–48 秒。叙事递进：

1. **问题出现**：档案／纸张／现场几何在镜头中打开，“一桩案件，远不止一个答案”。
2. **证据与研究**：指纹或痕迹被扫描、测量和重建，物证只是入口，“让事实，有据可循”。
3. **犯罪成因**：机会、环境、个体与社会关系连接为可解释的网络，“追问犯罪，如何发生”；网络是概念示意，不是实证数据。
4. **受害者视角**：断裂的关系、空缺或空间结构被重新连接，“看见伤害，也看见需要”。
5. **预防**：城市／街区几何、公共空间、支持网络发生改变，“把研究，变成更早的保护”；不能暗示监控能够预测某个人犯罪。
6. **司法与公平**：证据、程序、回应形成对称／平衡的几何结构，“让回应，经得起检验”。
7. **收束**：开场的线索以更完整、更强的形态回归，片名与行动主张在构图中落定。

这是一份方向，不是逐帧束缚。作者可以设计更好的视觉隐喻。重点是成品像宣传片，而不是七页课件。

## 视觉与动作

遵循根目录 SKILL.md、docs/TREATMENT.md、docs/ENGINE.md 的运动与构图原则，参考 opus55_code_video_guide.md 和 references/pdoom-study.md。

- 暖黑 #0a0908、信号橙 #ff4d12、骨白 #f4f1ea；允许少量纸白场景反转形成剪辑节奏。
- 技术档案、编辑设计、雕刻线条、强烈空间纵深。中文主标题要大且可读，细小英文标注只做次要层级。
- 每一幕拥有自己的几何动作与视觉结构。镜头推拉、遮罩切换、错相入场、强缓动、预备—冲击—过冲—回稳。
- 禁止通用粒子星云、代码雨、紫青霓虹、七幕同布局、纯靠淡入淡出的居中字幕卡。
- 标题参与构图，贯穿的橙色线索连接各幕。画面中不要出现播放器操作说明或实现技术说明。
- 不呈现真实人物／真实案件，不虚构统计、研究结论、机构背书。

## 交付与技术

- 新文件：`assets/criminology-opus55.html`。不要覆盖任何已有作品，也不要改动已有 app 引擎或用户修改。
- 单文件、自包含、双击可用；无 CDN、网络字体、外部图片或音频依赖。
- 选用适合构图的 Canvas / SVG / 内嵌 WebGL。避免为使用 Three.js 引入网络依赖。
- 每一帧由绝对时间决定：`render(t)`；随机固定种子，无跨帧粒子累积。可随意拖动、倒退、重播。
- 音乐如有，使用 Web Audio 原创合成的克制节拍、低频和冲击声音，第一次播放点击后启动。不要复用需要额外署名的现有音乐或内容不匹配的旧旁白。必须提供静音；无音频设备时视觉播放仍可正常工作。
- 播放／暂停、重播、可拖动时间轴、时间码、章节跳转、全屏、音频开关、隐藏控制。
- 空格播放暂停，方向键跳转 ±1 秒，方括号切换章节，H 隐藏控制。输入控件获得焦点时保留原生键盘行为。
- 画面随窗口等比缩放，移动端控件不溢出。键盘可操作、按钮有中文可访问名称。
- 可被程序检查：`window.render(t)`、`window.seek(t)`、`window.FILM = {duration, scenes}`（scenes 至少含 name、start、end）。
- 作者可以补充一个说明文件 `docs/CRIMINOLOGY-OPUS55-NOTES.md`。

## 验收

实际浏览器打开，检查无 JS 报错；每幕开头／中间／结尾抽帧；检查中文可读、无文字冲突、构图变化、所有切点。验证播放暂停、拖动、重播、静音、全屏、键盘和窄屏。只渲染 HTML，不压制 MP4。
