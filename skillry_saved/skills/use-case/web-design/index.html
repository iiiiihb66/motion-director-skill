How to build a website with a Skill

Three steps in Claude Code, Codex or Cursor. No design app needed.

  1. 1

    Paste the install prompt

    Copy the install prompt into your agent, or run the command below. The Skill lands in your agent's skills folder.

    npx skillry-cli@latest install bs-slate-admin-console
  2. 2

    Call it with a slash

    Type a slash and the Skill name, then say what you want in plain words.

    /bs-slate-admin-console Build a responsive landing page from this brief, copy, and brand kit.
  3. 3

    Review and ship

    Open the file it made, ask for changes in the same chat, then publish or hand it off.

    index.html

Web design Skills FAQ

What is a web design Skill?

A folder with a SKILL.md, layout references and checks that teaches your AI agent one proven website design. The agent loads it when you ask for a page.

Can Claude Code build a website with a Skill?

Yes. Install the Skill into Claude Code, describe the site, and it writes the HTML following the Skill's layout. Codex and Cursor work the same way.

Do I get HTML, React or a Figma file?

Most web design Skills deliver a working HTML file. Some also name Next.js or component output on their detail page; none ship a Figma file.

Are the website templates free?

Some are. Free Skills carry a Free label; the rest are included in Pro or can be bought one at a time.
