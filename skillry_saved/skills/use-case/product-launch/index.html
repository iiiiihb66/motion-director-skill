How to make launch assets with a Skill

Three steps in Claude Code, Codex or Cursor. No design app needed.

  1. 1

    Paste the install prompt

    Copy the install prompt into your agent, or run the command below. The Skill lands in your agent's skills folder.

    npx skillry-cli@latest install bs-hyperframes-code-change-launch
  2. 2

    Call it with a slash

    Type a slash and the Skill name, then say what you want in plain words.

    /bs-hyperframes-code-change-launch Create a launch page and campaign visuals from this product brief.

    Review and ship

    Open the file it made, ask for changes in the same chat, then publish or hand it off.

Product launch Skills FAQ

How do I make a product launch video with AI?

Install a launch video Skill and give your agent the product name or website URL. It writes a storyboard and renders the film. The Manus-style launch video Skill, for example, researches your site and delivers a 75–120 second MP4 in 1080p, 2K or 4K.

Do I need one Skill or several for a launch?

One is enough when a single piece is missing, such as the landing page. Use several when the same story has to run through a video, a page and a deck, and write the brief once so every Skill works from it.

Can the launch page take signups or payments?

Only if the Skill says it includes that integration. Most deliver the page itself, and you connect forms or checkout afterward. To compare page layouts and what each one delivers, see web design Skills.

Will the Skill make up product claims or pricing?

No. You supply the approved positioning, pricing and proof, and the Skill lays them out. It isn't meant to invent facts about your product.
