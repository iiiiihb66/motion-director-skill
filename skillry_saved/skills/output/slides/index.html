How to make a slide deck with a Skill

Three steps in Claude Code, Codex or Cursor. No design app needed.

  1. 1

    Paste the install prompt

    Copy the install prompt into your agent, or run the command below. The Skill lands in your agent's skills folder.

    npx skillry-cli@latest install bs-brand-story-deck
  2. 2

    Call it with a slash

    Type a slash and the Skill name, then say what you want in plain words.

    /bs-brand-story-deck Turn these company notes into a concise investor pitch deck.
  3. 3

    Review and ship

    Open the file it made, ask for changes in the same chat, then publish or hand it off.

    deck.html → .pptx

Slide deck Skills FAQ

Is there a Claude PPT Skill that exports to PowerPoint?

Yes. Every slide Skill here comes with a browser editing studio and PPTX export, so you can fix slides in the browser and keep editing in PowerPoint.

How is a slide Skill different from an AI presentation maker?

An AI presentation maker starts over with every prompt. A slide Skill keeps one tested design and story structure, so slide 20 looks like it belongs with slide 2.

How many slides will I get?

Usually as many as your outline needs. Each detail page explains how the Skill sets the slide count; the number of preview images is not the deck length.

Can it use our brand colors and fonts?

Yes, if the Skill takes brand inputs. Look for brand colors, fonts, a logo or reference images under Required inputs on the detail page.
