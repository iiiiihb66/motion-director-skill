How to make images with a Skill

Three steps in Claude Code, Codex or Cursor. No design app needed.

  1. 1

    Paste the install prompt

    Copy the install prompt into your agent, or run the command below. The Skill lands in your agent's skills folder.

    npx skillry-cli@latest install bs-grokbot-avatar
  2. 2

    Call it with a slash

    Type a slash and the Skill name, then say what you want in plain words.

    /bs-grokbot-avatar Create a 16:9 campaign hero and matching social media crops from this brief.
  3. 3

    Review and ship

    Open the file it made, ask for changes in the same chat, then publish or hand it off.

    image.png

Image Skills FAQ

How is an image Skill different from an AI image generator?

An AI image generator answers one prompt. An image Skill fixes the style, layout and checks, so every image you ask for matches the last one.

Which image model does it use?

Each Skill names its model and provider on the detail page. Many use FAL; generation is billed by that provider, not by Skillry.

Can the image include exact text?

Some Skills write text into the image; others leave a clean area for you to add exact labels. Check the detail page before you run it.

Can I use the images commercially?

Check the detail page and the provider's terms for each Skill. You are responsible for the content you publish.
