About this Skill

Starlit Deck — Storefront Guide

What you get

A complete presentation-building Skill that turns any outline into a starlit night-sky deck that behaves like a real presentation tool, not a scrolling webpage. The procedural CSS base deck is one self-contained, zero-network HTML file; if you opt into generated background art, the HTML ships with a companion images/ folder using local relative paths.

  • A verified paging engine — arrow keys, scroll wheel, and touch swipe move between full-screen 16:9 slides; ESC opens a thumbnail overview; N opens a speaker-notes panel; @media print rules export one slide per page for a clean PDF.
  • Eight night-sky slide archetypes ready to copy: cover, thesis statement, split layout, dot-flow process, arc timeline, point list, stat row, and a warm-horizon closing.
  • Three locked theme presets — Midnight Gold for narrative and retrospective decks, Aurora Teal for technical/product stories, Dawn Rose for personal and intimate talks.
  • Procedural CSS starfields that cost nothing to render, with an optional paid upgrade to painterly AI-generated backdrops.

The mood is fixed and deliberate: deep-navy sky, warm antique-gold serif headlines, scattered stars, and generous empty space. It reads as reflective and literary — ideal for founder letters, year-in-review talks, and company narratives rather than dense sales decks.

How a deck gets made

  1. You give the Skill your topic, audience, and any real material (numbers, milestones, quotes). 8–14 slides is the sweet spot.
  2. It picks a theme preset, copies the verified template, and plans one archetype per slide — never forcing layouts your story doesn't need.
  3. Slides are written with stable ids, numbered footers, and optional speaker notes.
  4. A validation script checks structure, page numbers, and background rhythm before the Skill pages through the result in a browser.
  5. Optionally — and only after asking — selected slides are upgraded from the procedural starfield to painterly AI illustrations.

What you need to prepare

  • A deck outline or content brief — the story you want told. Everything else has sensible defaults.
  • Optional: a FAL API key if you want AI-painted night-sky backgrounds (.bg-photo slides). The deck is complete without them — procedural starfields ship free.

Costs beyond the Skill

Only the optional background art step calls a paid API (FAL GPT-Image). Building, validating, and exporting decks costs nothing extra.

Runs in

Claude Code, Codex, Cursor, Copilot, and other coding agents. Ask for "a starlit retrospective deck about …" or share a gold-on-navy reference screenshot, and the Skill takes it from there.

Edit and export

The deck opens in a built-in editing studio. Change text, swap images, reorder slides and switch themes in the browser, then export an editable PowerPoint file or a PDF. In PowerPoint, text and speaker notes stay editable; backgrounds and decorations come across as pictures.
