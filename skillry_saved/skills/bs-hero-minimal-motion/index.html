About this Skill

You paste one block and the top of your page is finished — headline, supporting line, buttons and artwork already sitting right against each other. Nothing to lay out, nothing left grey.

What you get

  • The full source for Minimal Motion Hero — the component file plus a runnable usage example, ready to paste and edit.
  • A written visual contract: palette, type scale, radius, icon stroke and motion timings, all as tokens you edit in one place.
  • Responsive breakpoints already tuned, from desktop down to a phone.

How to use it

  1. Tell your assistant where the section goes and it reads your project first, then writes the block the way that project is already written.
  2. Replace the words with yours. The type sizes and spacing hold on their own.
  3. Change the accent colour in one place and the whole block follows.
  4. Look at it on a phone before you ship. It is already built to hold there.
