About this Skill

Turn a dense page, lesson, or rough brief into one visual note that explains the idea before the reader has to study every word. The result is a clean 4:3 English-first sketchnote with a large theme, a few exact labels, and hand-drawn illustrations that reveal the logic.

What you get

  • One finished visual note focused on a single idea
  • A clear process, cause-and-effect chain, hierarchy, comparison, or feedback loop
  • Three to seven illustrated nodes with short, checked English labels
  • Thin black pencil lines on white, with restrained red, yellow, and green accents

How to use

  1. Give it the selected text, document, or page you want explained.
  2. Add an audience or a must-keep term if either one matters.
  3. Review the proposed theme and labels, then approve image generation.
  4. Check the finished wording and visual flow before you share it.

English is the default for all examples and generated copy. Ask for another language only when your final audience needs it.

You need a FAL API key when your agent has no built-in image tool; FAL bills each generated or edited image separately.

What you need before you start
